# 🎨 Art Marketplace Clone

A responsive front-end clone of a modern online art marketplace platform, developed to demonstrate web development skills, UI/UX design principles, and e-commerce functionality.

## 📌 Project Overview

Art Marketplace Clone is a demo web application inspired by contemporary art-selling platforms. The project focuses on creating an engaging user experience for browsing, discovering, and exploring artwork through a clean and responsive interface.

This project was built for educational and portfolio purposes to showcase front-end development capabilities.

## ✨ Features

### 🖼️ Artwork Showcase

* Featured artwork collections

* Responsive image galleries
